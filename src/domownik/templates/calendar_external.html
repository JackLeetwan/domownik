Skąd wziąć link?
  • Kalendarz Google: na komputerze calendar.google.com → ⚙️ Ustawienia → wybierz kalendarz → „Integracja kalendarza” → Tajny adres w formacie iCal.
  • Outlook / Microsoft 365: Ustawienia → Kalendarz → Kalendarze udostępnione → „Opublikuj kalendarz” → link ICS.
  • Kalendarz iCloud: udostępnij kalendarz jako publiczny i skopiuj link webcal://.
  • Szkoła, przedszkole, klub: szukaj przycisku „Subskrybuj”, „iCal” albo „Dodaj do kalendarza”.

Link to klucz do kalendarza – Domownik pokazuje z niego tylko nazwę serwera.
